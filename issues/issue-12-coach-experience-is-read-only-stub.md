# Issue 12：教練點自己的課只會跳出一個唯讀 alert，沒有任何實用的自助功能

**嚴重程度：中**　**分類：教練體驗 / 功能完整度**　**發現時機：以教練角度評估系統時發現**

## 問題敘述

教練登入後點擊自己的課程（`static/assets/js/calendar.js` 的 `eventClick`），目前只會跳出瀏覽器原生 `alert()`：

```js
if (currentUser && currentUser.role === 'coach') {
    let msg = `課程名稱：${e.title}\n時間：...\n教練：${e.extendedProps.coach_name}`;
    if (e.extendedProps.is_trial) {
        msg += `\n【體驗課提醒】人數: ... 需收費: $... 元`;
    }
    alert(msg);
    return;
}
```

實測用教練帳號拉自己一週的課表（`GET /api/courses`），回傳的 `students` 陣列只有 `id / name / status`，**沒有電話**（對照學生本人或小編視角都會拿到 `phone`）。也就是說教練從系統裡完全看不到學生的聯絡方式。

綜合下來，教練在這個系統裡幾乎是「唯讀觀眾」：

- 看得到自己的課表、學生姓名、體驗課費用（這些做得不錯）。
- 但看不到學生電話、看不到學生剩餘點數／堂數。
- 不能標記出席／缺席（`checkin` 是 `@admin_required`）——即使教練才是實際在場、最清楚誰有沒有來的人。
- 不能自己申請調課／請假（只能透過小編）。
- 沒有自己的個人資料編輯頁面——後端 `PUT /api/users/<id>` 其實允許本人改自己的 `phone`/`nickname`/`line_id` 等欄位（`SELF_SERVICE_FIELDS`），但整個網站沒有任何頁面把這個功能露出來給教練用（`/add_user`、`/users` 都是 `admin-only`，學員專屬的 `/student/portal` 也只給學員）。

## 影響

以「這是不是我會想用的系統」的角度來看，教練每天真正會遇到的狀況——學生沒來要不要聯絡、想跟小編確認這堂課要不要簽到、想改自己的聯絡電話——目前都得跳出系統另外用 LINE 或口頭溝通，系統本身幫不上忙。長期下來教練可能只把這個網站當成「看課表用」，其他還是回到舊有的溝通方式，等於系統只發揮了一部分價值。

## 建議修復方向（可視優先度分批處理）

1. 把教練點課程跳出的 `alert()` 換成跟小編一樣的彈窗（唯讀版本即可），至少能看到完整資訊而不是一段純文字。
2. 課程資料回傳給教練時，補上學生電話（教練本來就看得到學生姓名，電話對「聯絡沒來的學生」是剛需，风险可控）。
3. 提供一個教練專屬的簡易個人資料頁（比照 `/student/portal` 的「個人資料」分頁），讓教練能自己改電話、LINE 等聯絡資訊，不用麻煩小編代為修改。
4. 是否開放教練自己標記出席／請假，屬於信任邊界的商業決策（目前 `task.md` 明確寫「教練唯讀不可新增修改」），不一定要改，但建議至少讓教練能看到「這堂課有沒有被簽到」的狀態，而不是完全沒有回饋。
