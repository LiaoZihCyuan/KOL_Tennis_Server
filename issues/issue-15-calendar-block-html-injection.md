# Issue 15：排課看板的課程方塊直接把文字當 HTML 插入（XSS）

**嚴重程度：中（目前只有小編能輸入，實際風險低）**　**分類：安全性**　**發現時機：verifier 驗證「編輯課程可改備註」時（2026-10-17）**　**狀態：待處理**

## 問題敘述

`static/assets/js/calendar.js` 的 `eventContent`（課程方塊、清單檢視）用樣板字串組 HTML，以下欄位都**沒有經過 `escapeHtml()`** 就插入畫面：

- 學生/課程名稱 `${student}`（`arg.event.title`）
- 程度/備註 `${level}`（課程 `description`）
- 教練名稱 `${coach}`

如果其中任何一個欄位含有 HTML（例如 `<img src=x onerror=...>`），就會在每個打開看板的人（小編、教練、學生）瀏覽器裡執行。

## 目前的輸入管道

- 新增課程表單的「學生」「程度/備註」（小編）
- 編輯課程表單的「學生姓名」「程度/備註」（小編；備註欄於 2026-10-17 新增）
- 固定課表模板的課程名稱、程度/備註（小編）→ 自動產生的課程會帶過去
- 使用者的顯示名稱（學生自助修改個人資料也能改 `display_name`，需確認是否會出現在課程方塊）

## 對照

同一個檔案的公告面板、請假名單，以及 `templates_manage.html` 的固定課表圖表都已經用 `escapeHtml()`，只有看板課程方塊漏掉。

## 修正方向（待與使用者確認）

- `eventContent` 內所有來自資料的文字一律 `escapeHtml()`。
- 盤點其他頁面是否有同樣的直接插入（`innerHTML` + 樣板字串）。
